Five gates before any tool

TypePractical guide
Time6 min + 2 min check
NO IT NEEDED
You'll learnWhy a slow step is often not the real problem · the order to check things in · what to fix at each gate
You getThe five gates, step by step · a two-minute check for your own task

Someone says a task is slow, and the next sentence is "can we automate it?". Sometimes the answer is yes. Often the slow step is only where the problem shows, not where it starts.

A tool copies the way a task is done today, with the data it is given. If the task is too small, the data is wrong, the information lives on paper or nobody does it the same way twice, the tool copies that too. It just does it faster.

So before anyone prices a tool, a task goes through five gates. The order matters. Each gate is cheaper to check than the next, and each one stops money going into the wrong fix.

The five gates

1

Worth it?

Fails: leave it

Two questions. Does it take enough time to matter, and can it be done by rules? Fifteen minutes a week is about twelve hours a year. A tool would cost more than it saves. A task that needs a judgement call every time, like deciding which late order goes first, can't be handed to a tool either.

A typical case: a short price list from a supplier, typed into a spreadsheet once a week.

InsteadA saved filter, a template or a checklist. Come back if the hours grow.

2

Data right?

Fails: fix the data first

The step may be fine, but the information it starts from can't be trusted. A tool works from that data, so it would give the wrong answers faster. Fixing the data means fixing the process that feeds it, not the spreadsheet.

A typical case: picking feels slow, so the ask is to sort the picking route. But stock isn't where the system says it is, and the counts never match. A perfect route to the wrong shelf saves nothing.

InsteadTrace one wrong value back to where it went wrong. In a warehouse that is booking in, moving or booking out. Count one small area and compare it with the system.

3

On screen?

Fails: get it off paper first

Nothing can be automated while it lives on paper. If the information is written on a sheet and typed in later, the first step is digitalisation: capture it on a screen where it happens, not at the end of the week.

A typical case: inspection results written by hand, typed into a spreadsheet on Friday, and the mistakes found by the customer.

InsteadKeep the same form, but fill it in on a tablet or PC at the same spot. That is often the first small tool, and it can be priced on its own.

4

One way?

Fails: write the steps down first

If every shift does it differently, which way should the tool copy? Without one agreed way, a tool copies the confusion and people work around it. One person knowing the job is not the problem. Nobody being able to write it down is.

A typical case: three shifts pack and label orders three different ways, and each is sure theirs is right.

InsteadWatch two people do it, note where they differ, agree one way and write it as a short checklist. Run it for a few weeks.

5

Automate

Passes the first four gates: worth a tool

It happens often, takes real hours, follows rules, starts from data you can trust and is done one way. Now a tool pays. Built around the way your team already works, it takes the step off someone's desk and does it the same way every time.

A real one: about 80 job sheets a day, sorted by hand for an hour. The rules were clear and the data came from the ERP. Now it takes about a minute. Watch it run →

Why this order

Each gate is cheaper to fix than the one after it. Checking is free. Fixing data or a habit costs time, not money. A tool costs money. Doing them in the wrong order means paying for the expensive fix and still having the cheap problem.

1 · Worth it?a few minutes of honest sums
2 · Data right?days, on the floor
3 · On screen?a form, or a small tool
4 · One way?weeks of practice
5 · Automatea fixed-price tool

Most tasks fail one of the first four gates on the first try. That is not bad news. It means the cheapest fix comes first, and the tool, when it comes, has something solid to stand on.
