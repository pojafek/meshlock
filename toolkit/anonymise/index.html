File anonymiser

Someone outside the company needs a real export to work with: a supplier, a consultant, Meshlock too. Run the file through here first. Names, emails, codes and prices are swapped for stand-ins that keep the shape of the data, so whatever gets built on it still works on the real thing.

What stays the same

  • The same customer gets the same stand-in everywhere: in every column and in every file you add together.
  • Codes keep their length and pattern. Letters stay letters, digits stay digits, dashes stay where they were.
  • Dates move by whole weeks, so a Monday stays a Monday and the gaps between dates don't change.
  • Prices are multiplied by one hidden factor, so a dearer item stays dearer and line totals stay in proportion.
  • Excel files keep their sheets, columns and formatting. Links become plain text, cell notes and author details are cleared, and rows above the header row are left out.

Keep the key

The key lists every stand-in next to its real value. It stays with you. When an answer comes back full of stand-ins, the key tells you who Customer 014 is. Add it next time and the same customer gets the same stand-in again.

Check by eye before you send

The check finds real values from swapped columns wherever else they turn up. It can't know about a name that never sits in a swapped column. So look over:

  • Free text, like notes and comments. Empty them unless they are needed.
  • File names and sheet names.
  • Pictures and logos inside a spreadsheet.
  • PDFs, scans and photos. This tool doesn't read them, so make up two or three examples instead.
