Quality & error-proofing

Cut file check: a digital quality gate

Up to 10% of machine capacity freed

⤢ Full screen
Challenge

New designs went to the machine to find out if they were right. Test cut, count the parts by hand, find the error, bin the sheet, fix it, repeat. About an hour on every new design.

Approach

A digital quality gate, built from scratch. Every file is checked on screen before the first cut: orientation, position, gaps in cut paths, processing settings, part count against the paperwork and part ID. Each issue is marked on the drawing and fixed in the file before it reaches a machine.

Outcome

Errors caught on screen, not in the bin. About an hour saved on every new design, and up to 10% of machine capacity freed.

Data & reporting

Machine data: downtime you can see

80% → 91%

⤢ Full screen
Challenge

The machines ran all day and nobody knew how well. Every stop was in the logs, but nobody could see it. Daily performance was a guess.

Approach

Machine logs pulled automatically, with every start and stop tracked to the second and shown per machine. With the downtime visible, the causes were found, the process changed and operators were trained on the real data.

Outcome

Average machine performance up from 80% on the first measured day to 91%. Same machines, same people.
